Reads as records rather than a grid, which matches the data: one row per borough group, so adding Tower Hamlets is "New borough group" and Copy from… seeds it from Lambeth & Southwark. The full segmented control has room for the reason under each label — "Closed by stock — 0 available", "Not stock-tracked" (Auto disabled where there's no stock signal) — which the matrix can only show on hover. Limits and organisation overrides sit inside the borough they belong to, and the footer strip states the resulting public offer so a mis-set toggle is obvious before saving. Cost: no cross-borough comparison at a glance once there are four or five groups.
