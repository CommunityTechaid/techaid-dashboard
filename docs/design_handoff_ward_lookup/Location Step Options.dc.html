2bSame page, three access modes (hidden → invite → open)
One page, an access setting you flip when you're ready
Same URL throughout — no re-sending links to partners when the project opens up.
Mode 1 · Unlisted
link-only, no sign-up
Page loads normally for anyone holding the link. No index, no nav entry, a quiet banner so partners know it's a pilot.
Pilot — please don't share this link outside your team yet.
Mode 2 · Invite code
link can leak, access can't
A short code per organisation. Entering it names the partner, so quotas and borough scoping work without building logins.
Codes are revocable and expire — the safe middle step between pilot and public.
Mode 3 · Open
listed publicly
Code step drops away, page appears in navigation. Capacity is protected by quota rather than by obscurity.
Waiting list — we're at capacity this month. Join the list and we'll be in touch in September.
Answers the hidden-URL question directly: yes, and better than a secret link. Because it's a setting rather than a different page, opening up later is a toggle in the admin config — nothing to rebuild or re-share.
